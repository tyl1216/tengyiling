Lucide SVG · iOS 风格 · safe-area 适配

🧊 iOS 毛玻璃效果：backdrop-filter: blur(20px)，颜色穿透，层次细腻。
📍 发现 有红点，消息 有 3 条未读。徽章用绝对定位叠在 img 右上角。
🎨 Lucide SVG 用 CSS filter: brightness(0) invert(...) 改颜色—— 因为 img 引用 SVG 时，color CSS 属性不生效，只能用 filter hack。
📱 viewport-fit=cover + env(safe-area-inset-bottom) 适配刘海屏。
✨ 点击切换 active 状态，SVG 颜色从 iOS 灰 #999 切换为 iOS Blue #007AFF。
🔗 iconfont-3（字体图标版）用的是 font/iconfont.css；本页（SVG 版）用的是 cdn/lucide/*.svg。
