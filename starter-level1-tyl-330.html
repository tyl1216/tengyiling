/*-----分数相关计算逻辑总结-----*/ 数据源：STUDENTS（学生对象）、SUBJECTS（科目数组），及格线固定 60 单个学生总分 getTotal(s) 遍历所有科目，把该学生每一科分数累加 plaintext 总分 = 所有科目分数相加 单个学生平均分 getAvg(s) plaintext 平均分 = 该学生总分 ÷ 科目数量，保留1位小数 判断单科样式 scoreClass(v) 分数＜60 → fail（红色，不及格） 分数≥100 → full（绿色，满分） 其他：无样式 查找学生不及格科目 getFails(s) 筛选该学生分数＜60 的科目，返回不及格科目数组 数组长度 = 这名学生挂了几科 面板顶部【班级总分数】（所有学生所有分数总和） 双层 reduce：循环每一个学生，再循环每一个科目，全部分数累加 plaintext 班级总分 = 所有学生所有科目分数之和 面板顶部【班级平均分】（整张试卷全局平均分） plaintext 班级平均分 = 班级总分 ÷（筛选后的学生人数 × 科目总数） 及格率（重点！不是平均分及格） 及格定义：该学生没有任何一科不及格 plaintext 及格人数 = 筛选列表里，getFails(s).length === 0 的学生数量 及格率 = 及格人数 ÷ 当前筛选总人数 × 100，取整数 不及格预警排序规则 筛选出有挂科的学生，按挂科科目数量从多到少排序，挂科越多排在越前面 📌 一句话串起来 先拿学生每科分数，算个人总分、个人均分；再统计全部学生所有分数得到班级总分、 班级均分；再看谁没有任何一科不及格，算出及格率；预警区按挂科科目多少排序。 //整体作用 本页面是学生成绩分析面板，使用原生 HTML+CSS+JavaScript 实现 ，外部data.js提供学生、科目原始数据。页面骨架由 HTML 搭建，CSS 负责布局、配色、交互样式； JS 负责数据处理、DOM 动态渲染、搜索排序交互。 整体数据流：原始学生数据 → 搜索过滤 → 排序 → 一次性渲染三大模块。 模块分工 CSS：定义主题变量、全局样式、卡片、网格、按钮、预警列表等样式，实现渐变背景、卡片悬浮、激活高亮、不及格标红满分标绿等视觉效果。 HTML：只提供静态容器，划分 4 个业务区块：班级概览统计、数据操作区、不及格预警、学生卡片区，所有数据内容由 JS 动态生成。 JS 工具函数：封装分数样式判断、总分、平均分、查找不及格科目、提取姓名首字，供核心函数复用。 5 个核心业务函数 renderStats：统计筛选后班级人数、总分、全体平均分、无挂科及格率，写入统计卡片； renderStudentCards：循环生成学生卡片，展示头像、姓名学号、排名、各科分数、总分均分； renderFailWarning：筛选挂科学生，按挂科科目数量降序展示预警名单； search：模糊搜索，支持姓名、学号检索，大小写不敏感； sortList：支持总分降序、学号升序两种排序，复制数组不污染原始数据。 主调度 refresh()：页面刷新入口，每次搜索、切换排序都会执行，串联过滤、排序、渲染。 事件：搜索输入防抖，减少频繁渲染；排序按钮使用事件委托，切换排序规则并高亮当前按钮。 初始化：页面加载自动调用refresh()，首次渲染全部数据。
